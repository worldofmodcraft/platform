# ADR-0060: Public but unannounced until Ludwig declares a stable release

- **Status:** Accepted · **Date:** 2026-09-02 · **Area:** Governance
- **Related:** ADR-0006, ADR-0078, ADR-0094

## Decision
Repositories are public from day one (openness principle) but the project is **unannounced**: no announcements, devlogs, Discord, or posts anywhere. Going public is **solely Ludwig's decision**, expected around a stable release (roughly 1.0-class quality) — explicitly *not* at the working slice. No future session may "helpfully" start marketing. Targeted, private contacts (e.g. the WoWee or mod-ale authors) are allowed without a public stage. Visibility-coupled features (server directory ADR-0078, code signing ADR-0094) sit behind the same threshold.
