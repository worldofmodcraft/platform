# ADR-0030: Manifest and mod folder structure

- **Status:** Accepted
- **Date:** 2026-09-01
- **Area:** Mod format
- **Related:** ADR-0011, ADR-0021, ADR-0028, ADR-0032, ADR-0034

## Decision
Folder:
```
mymod/
  mod.lua              manifest
  README.md  LICENSE
  records/             .lua and .json records
  server/init.lua      server-side Lua
  client/init.lua      client-side Lua
  plugins/             C/C++/Rust source; the site builds
  assets/              glTF/GLB, PNG, OGG (whitelist)
  sql/                 migrations for prefixed tables
  config.schema.lua    user-configurable settings
  tests/               modcraft test files
  AGENTS.md            AI tooling instructions (generated by modcraft new; CLAUDE.md symlink)
```
`mod.lua` returns a table with: `id` (`namespace:name`), `name`, `version` (semver), `api_version`, `license`, `source`, `type` (`"mod"` | `"modpack"`), `description`, `tags`, `screenshots`, `ai_assisted` (true / false / omitted — omitted shows nothing), `depends`, `optional`, `conflicts` (version-bound), `load_after`, `extends`, `provides` / `wants` (capability tags, ADR-0032), `permissions` (ADR-0028), `server = { lua, plugin }`, `client = { lua, plugin }`, `data_version`, `client_optional` (for purely cosmetic mods a player may disable locally), and **`declares`** = `{ hooks, emits, listens, record_types = { defines, modifies }, rpc, tables, roles/permissions provided }`.

`declares` is mandatory and checked twice: the site's static analysis rejects code touching anything undeclared; the kernel warns at runtime if it happens anyway. The declaration doubles as documentation on the site.

The **namespace is the GitHub username** (ADR-0039). **Tier and signature are set by the site**, never by the mod. Everything is **English**; no `locale/`. A no-op `t("...")` may exist in the kernel so a community translation mod is possible later.
