# ADR-0003: Naming

- **Status:** Accepted
- **Date:** 2026-09-01
- **Area:** Vision

## Decision
- The platform is **World of Modcraft**.
- The kernel (the shared runtime library and CLI) is **modcraft**; the CLI command is `modcraft`.
- The namespace for platform-provided core mods is **`mc:`** (e.g. `mc:entities`, `mc:placeholders`).
- The web portal is **worldofmodcraft.com**.
- The custom protocol URI for launcher integration is **`modcraft://`**.

## Consequences
- All identifiers, documentation and user-facing text use these names consistently.
