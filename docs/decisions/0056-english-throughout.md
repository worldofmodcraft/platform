# ADR-0056: English throughout

- **Status:** Accepted
- **Date:** 2026-09-01
- **Area:** Governance / Documentation
- **Related:** ADR-0006, ADR-0030

## Decision
All repository content — code, comments, documentation, this decision log, error messages, user-facing text in kernel, launcher and site — is in English, from day one. No localisation layer in v1 (a no-op `t()` may exist so a community translation mod is possible later). Conversation between the project owner and the AI may be in Swedish; artefacts are not.
