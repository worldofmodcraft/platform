# ADR-0036: Opt-in diagnostics sharing to worldofmodcraft.com

- **Status:** Accepted
- **Date:** 2026-09-01
- **Area:** Telemetry / Privacy
- **Related:** ADR-0034, ADR-0037, ADR-0038

## Decision
- **One opt-in:** "Share diagnostics", with an explanatory text along the lines of: community-driven modding of WoW carries a real risk of crashes; this data helps the community fix problems for everyone. Off by default.
- **What is sent:** per-session **summaries**, never raw logs: session header; duration; per mod — warn/error counts grouped by traceback signature, crash yes/no with attributed mod, leak flags, budget overruns per hook, deprecated-API warnings; platform package version. On crash: the last ~200 events and stack trace (covered by the same opt-in). Also: connection failures and at which step (not to whom).
- **What is never sent:** character names, chat, IP, account names, paths containing usernames. Masking happens **locally**, before the summary is built.
- **Everything sent is stored locally** and viewable via "Show diagnostics data shared". Local log level does not affect the summary.
- **Pseudonymous installation id:** random, generated by the launcher, never linked to name/email/IP. "Delete everything I shared" removes all reports; the site keeps only `id, deleted_at, deletion_count`. The id is **not** rotated on deletion (so continued reports remain visible as a pattern); "Create new id" is a separate button. The local view shows "You deleted shared data on <date>. New reports since: N". The opt-in text states the deletion flag in plain words.
- GDPR: opt-in is the basis; the data is pseudonymous; deletion is honoured.
